## 📖 Mini Guia de Estudo (Entrega Final)

### 📌 Resumo Estruturado
O GitHub é uma plataforma essencial para o armazenamento seguro e o desenvolvimento colaborativo de software. Suas principais funcionalidades incluem:

1. **Repositórios:** Funcionam como pastas na nuvem. Podem ser públicos (visíveis a todos) ou privados. O arquivo **README** é a porta de entrada, onde se explica o projeto e as necessidades de ajuda.
2. **Canais de Auxílio:**
    - **GitHub Discussions:** Fórum para debates, ideias e perguntas conceituais.
    - **GitHub Issues:** Registro formal para relatar bugs ou sugerir melhorias específicas.
    - **Pull Requests:** Propostas de alteração no código que podem ser revisadas e aceitas pelo dono do projeto.
3. **Modelo de Colaboração (Fork and Pull):** O colaborador faz uma cópia do projeto (**Fork**), realiza as melhorias e envia a sugestão de alteração (**Pull Request**) para o projeto original.

### 📖 Glossário de Conceitos
- **Repositório:** Espaço onde ficam armazenados todos os arquivos de um projeto e seu histórico de alterações.
- **Fork:** Criar uma cópia exata de um repositório de outra pessoa para a sua própria conta.
- **Pull Request (PR):** Uma solicitação para que as alterações feitas em um fork sejam incorporadas ao projeto original.
- **Issue:** Um "ticket" ou chamado usado para reportar erros ou sugerir novas funcionalidades.
- **README:** Arquivo de texto (Markdown) que serve como manual de instruções do projeto.
